Guide

Track Codex usage without an API key.

CodexBar Lite uses the Codex CLI session already on your Mac to show usage and reset times without asking for another credential or sensitive system access.

Why an API key is not required

When you run codex login, the Codex CLI creates a local authenticated session for your ChatGPT account. CodexBar Lite reuses that existing session instead of asking you to create, paste, or store an OpenAI API key. This also means the app tracks the Codex allowance included with your ChatGPT plan rather than separate API billing.

What CodexBar Lite reads

The app reads one local file: ~/.codex/auth.json. That is the same session file created by the Codex CLI. It uses the account context in that session only to request your usage; it does not inspect browser profiles, copy browser cookies, or retrieve credentials from the macOS Keychain.

Where the usage request goes

CodexBar Lite sends the minimum request needed to retrieve usage directly to chatgpt.com. There is no CodexBar Lite backend or third-party account between the app and OpenAI. On your Mac, the app stores only its preferences and a local usage cache so it can remain useful when you are briefly offline.

Permissions it does not need

  • No OpenAI API key
  • No browser cookies or browser-profile access
  • No macOS Keychain access
  • No Full Disk Access
  • No Accessibility or Screen Recording permission
  • No third-party account

This narrow permission model is possible because CodexBar Lite tracks only Codex. If you are deciding between single-provider and multi-provider tracking, read the CodexBar alternative comparison.

How to start tracking

  1. Install CodexBar Lite on an Apple Silicon Mac running macOS 13 or newer.
  2. Open the app.
  3. If a Codex session does not exist, complete the codex login flow the app opens in Terminal.
  4. Read your current usage from the menu bar and open the popover for both reset windows.

For the other available methods, see how to check OpenAI Codex usage and rate limits. To understand the percentages and reset clocks, read how Codex usage limits and reset times work.
