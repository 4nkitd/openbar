Guide

Track Codex usage without an API key.

OpenBar uses existing CLI sessions on your Mac or optional Keychain credentials to display usage and reset times without requiring third-party servers.

Why an API key is not required

When you run codex login, the Codex CLI creates a local authenticated session for your account. OpenBar reuses that existing session (or Keychain tokens) instead of requiring a separate paid API key. This means the app tracks the usage included with your plan subscription rather than separate API billing.

What OpenBar reads

The app detects local session files like ~/.codex/auth.json created by the Codex CLI or credentials stored securely in your macOS Keychain for configured accounts. It uses account credentials only to request your usage directly from provider endpoints; it does not inspect browser profiles, scan browser cookies, or require Full Disk Access.

Where the usage request goes

OpenBar sends the minimum request needed to retrieve usage directly to provider APIs (such as chatgpt.com). There is no OpenBar backend or third-party server between the app and the provider. On your Mac, the app stores account preferences and timestamped usage readings locally in ~/Library/Application Support/OpenBar/accounts-v1.json so it remains responsive offline.

Permissions it does not need

  • No required API key for session-based tracking
  • No browser cookies or browser-profile scanning
  • No third-party backend account or tracking server
  • No Full Disk Access
  • No Accessibility or Screen Recording permission

If you are deciding between menu bar tracking tools, read the CodexBar alternative comparison.

How to start tracking

  1. Install OpenBar on a Mac running macOS 13 or newer.
  2. Open the app and configure your accounts in Settings.
  3. If a local session exists (from codex login), OpenBar detects it automatically, or add credentials via Keychain.
  4. Read current usage and reset times right from your menu bar.

For other available methods, see how to check OpenAI Codex usage and rate limits. To understand percentages and reset clocks, read how Codex usage limits and reset times work.
